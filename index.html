Cómo ponerlo en línea (multiusuario y automático)

  1. Cree una Hoja de cálculo de Google vacía llamada Biocirculo Programacion.
  2. Menú Extensiones → Apps Script. Borre el contenido y pegue el código de abajo. Guarde.
  3. Implementar → Nueva implementación → Tipo: Aplicación web. Ejecutar como: Yo. Acceso: Cualquier persona. Copie la URL que termina en /exec.
  4. Pegue esa URL arriba en "URL de sincronización" y guarde. Desde ese momento todo se guarda en la hoja (pestañas solicitudes, ubicaciones, inventario, vehiculos) y se actualiza cada 30 segundos en todos los equipos.
  5. Publique este archivo HTML (SharePoint/OneDrive con enlace, GitHub Pages, o como archivo compartido) y entregue los enlaces por rol:
    • Promotora: …archivo.html?rol=promotora&nombre=LUZ
    • Conductor: …archivo.html?rol=conductor&placa=GDY421
    • Coordinación: el enlace sin parámetros.
  6. Para el GPS del conductor el archivo debe abrirse desde una dirección https (por ejemplo GitHub Pages) y el celular debe permitir la ubicación.
